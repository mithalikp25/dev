# 🎮 HTML & CSS Mini Games

This repository features mini-games created using HTML and CSS. Currently, it contains the **first game**:

1. **Shape Game** – Interactive shapes with hover effects:
   - Square changes color on hover
   - Rotated square/diamond with upright text
   - Circle changes color on hover

Other two games will be added soon!

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Hover over the shapes to play and see interactive effects.

## Tech Used

- HTML5
- CSS3 (Flexbox, hover effects, transforms)
