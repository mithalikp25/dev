# 🎮 HTML & CSS Mini Games

This repository features multiple **mini-games and interactive designs** built purely using **HTML and CSS**.  
Each mini project demonstrates creative use of **Flexbox, transforms, hover effects, and positioning**.

---

## 🕹️ Games Included

### 1. **Shape Game**

Interactive shapes with fun hover effects:

- A **square** that changes color on hover
- A **rotated diamond** (square rotated 45°) with upright text
- A **circle** that changes color on hover

### 2. **Card Stack Game**

A stack of **rotated image cards** with hover interactions:

- Cards overlap with layered rotations using `z-index`
- Hovering over a card brings it to the front
- Styled with smooth positioning and `object-fit: cover` for clean visuals

---

## 🚀 How to Run

1. Clone or download this repository.
2. Open any of the `.html` files (e.g., `index.html` or `cards.html`) in your browser.
3. Hover over elements to see the interactive effects in action.

---

## 🛠️ Tech Used

- **HTML5**
- **CSS3** (Flexbox, transforms, positioning, hover effects)
